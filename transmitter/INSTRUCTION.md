# Transmitter (Telegram Remote Assistant)

## Что это?
Это ваш личный шлюз (Telegram Bot) для управления вашим проектом прямо с телефона, когда вы находитесь вдали от компьютера. Вы можете давать команды терминалу, читать файлы, собирать проект и получать отчеты прямо в Telegram.

## Как установить в любой другой проект?
1. Просто скопируйте всю папку `transmitter` в корень вашего нового проекта.
2. В терминале перейдите в эту папку: `cd transmitter`
3. Установите зависимости: `npm install`
4. Настройте ваш токен в файле `.env` (если он изменился).
5. Запустите бота: `npm start` (или используйте `pm2 start bot.js` для работы в фоне).

## Как общаться с ИИ через этого бота?
Поскольку я (Antigravity IDE Assistant) привязан к вашему редактору кода на ПК, я не могу напрямую писать вам в Telegram, когда редактор закрыт. Однако, вы можете использовать этого бота как "мост":

1. **Запуск команд:** Вы можете использовать команду `/cmd git pull` или `/cmd npm run build`, чтобы удаленно управлять проектом.
2. **Получение отчетов:** Если у вас есть скрипты тестов (например, `/cmd npm run test`), бот пришлет вам полный отчет прямо в чат.
3. **Чтение кода:** `/read src/app/api/route.ts` - позволяет прочитать код.

*Совет:* Если вы хотите, чтобы этот бот сам писал код как ИИ, вы можете добавить в него интеграцию с OpenAI или Gemini API. В `bot.js` уже есть обработчик обычных текстовых сообщений (`bot.on('message'...)`), куда можно легко добавить вызов API ИИ.

## Доступные команды по умолчанию
- `/help` — список всех команд
- `/cmd <ваша команда>` — выполнение любой команды в терминале (от корня проекта)
- `/read <путь>` — чтение файла
- `/ls <путь>` — просмотр содержимого папки
- `/ping` — проверка статуса бота
