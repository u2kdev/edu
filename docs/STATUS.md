## 3. Безопасность и Архитектура
- **Tenant Изоляция (centerId):** Строгая. Во всех бизнес-эндпоинтах используется `getTenantDb(tenantCtx.center.id)`. Во всех операциях `.create()` / `.update()` поле `centerId` берется исключительно из проверенного контекста `requireTenantAccess()`.
- **Чистота типизации:** 0 вхождений `as any`, `@ts-ignore` и `@ts-expect-error` во всем проекте (`src/` и `tests/`).
- **Блокировка центров:** При статусах `PAUSED`, `BLOCKED`, `CANCELLED` доступ через `requireTenantAccess` возвращает 403 `CENTER_SUSPENDED`.
- **dev-login:** Строго защищен (`NODE_ENV === "production"` и `DEV_LOGIN !== "true"` возвращают 404).

## 4. Качество и Тесты
- **Всего файлов тестов:** 31 файл (29 интеграционных на реальной SQLite БД + 2 юнит-теста на моках `*.unit.test.ts`).
- **Всего тестов:** 165 тестов (100% пройдены, 0 failed).
- **Изоляция:** Включен `fileParallelism: false` в `vitest.config.ts` для исключения файловых блокировок SQLite (`EBUSY`, `database is locked`).
- **Идемпотентность:** Гонки уникального ключа `(lessonId, studentMembershipId)` обрабатываются через fallback на `updateMany`.

- Файл `.github/workflows/ci.yml` запускается на `push` и `pull_request` для веток `feature/lms-upgrade` и `main`.
- Шаги: `npm ci` → `prisma generate` → `prisma db push` → `tsc --noEmit` → `next lint` → `vitest run` → `next build`.
