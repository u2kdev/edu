## 2. Что сверяет `tests/i18n.test.ts`
Тест [`tests/i18n.test.ts`](file:///d:/AZIZ%20PROJECT/tests/i18n.test.ts) импортирует словари напрямую из `src/locales/`:
```typescript
import ru from "../src/locales/ru.json";
import uz from "../src/locales/uz-Latn.json";

describe("i18n", () => {
  it("should have matching keys in ru.json and uz-Latn.json", () => {
    const ruKeys = Object.keys(ru).sort();
    const uzKeys = Object.keys(uz).sort();

    expect(ruKeys).toEqual(uzKeys);
  });
});
```
Он валидирует **симметрию ключей** (100% совпадение множества ключей) между `ru.json` и `uz-Latn.json`. На текущий момент оба словаря содержат идентичный набор из 22 ключей.

## 4. Клиентский / Серверный хелпер переводов
В модуле [`src/lib/i18n.ts`](file:///d:/AZIZ%20PROJECT/src/lib/i18n.ts) реализована функция `t(key: string, lang: string = "ru")`:
```typescript
import ru from "../locales/ru.json";
import uz from "../locales/uz-Latn.json";

const locales: Record<string, Record<string, string>> = {
  ru,
  "uz-Latn": uz,
};

export function t(key: string, lang: string = "ru"): string {
  const dictionary = locales[lang] || locales["ru"];
  return dictionary[key] || key;
}
```
