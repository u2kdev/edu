# Архитектура и состояние Интернационализации (i18n)

## 1. Расположение словарей
В проекте используются две структуры локализации:
1. **Базовый плоский словарь (`src/locales/`):**
   - [`src/locales/ru.json`](file:///d:/AZIZ%20PROJECT/src/locales/ru.json) — **21 ключ**.
   - [`src/locales/uz-Latn.json`](file:///d:/AZIZ%20PROJECT/src/locales/uz-Latn.json) — **21 ключ**.
   - Проверяется тестом `tests/i18n.test.ts` на 100% совпадение ключей.
2. **Иерархический словарь платформы (`src/i18n/locales/`):**
   - [`src/i18n/locales/ru.json`](file:///d:/AZIZ%20PROJECT/src/i18n/locales/ru.json) — **391 ключ** (17 секций: common, auth, nav, roles, dashboard, courses, groups, students, lessons, materials, attendance, homework, payments, invites, staff, parent, notifications, landing).
   - [`src/i18n/locales/uz-Latn.json`](file:///d:/AZIZ%20PROJECT/src/i18n/locales/uz-Latn.json) — **391 ключ** (100% паритет с русским словарем).
   - Используется клиентской и серверной функцией `t(locale, keyPath, params)` из `@/i18n`.

---

## 2. Локализованные модули без хардкода

Все фрагменты русскоязычного хардкода в ключевых компонентах модулей CORE-1, CORE-2, CORE-3, CORE-4, CORE-5, SaaS-лендинга (БЛОК 8) и модуля курсов полностью переведены на вызовы `t(locale, ...)`:

1. **`src/components/StudentsManager.tsx` (CORE-1):**
   - Пагинация: `t(locale, "students.pageOf", { page, totalPages })`
   - Инвайт-код: `t(locale, "students.studentCreatedInvite")`
   - Опция без группы: `t(locale, "students.noGroupSelected")`
   - Подписи сортировки: `t(locale, "students.sortAsc")`, `sortDesc`, `sortNewest`, `sortOldest`
   - Ошибки импорта CSV: `t(locale, "students.csvErrorRow", { row, error })`
2. **`src/components/GroupsManager.tsx` (CORE-1):**
   - Алерт перевода: `t(locale, "groups.transferSuccess")`, `transferError`
   - Алерт отчисления: `t(locale, "groups.dropSuccess")`, `dropError`
   - Преподаватель карточки: `t(locale, "groups.teacherAssigned")`, `teacherNotAssigned`
   - Заголовок списка: `t(locale, "groups.rosterTitle", { count })`
   - Опция без учителя: `t(locale, "groups.noTeacher")`
   - Метка студента: `t(locale, "groups.studentLabel", { name })`
   - Причина перевода: `t(locale, "groups.transferReasonLabel")`
   - Подтверждение отчисления: `t(locale, "groups.dropConfirm", { name })`
   - Ошибки сохранения/сети: `groups.saveError`, `groups.networkError`
3. **`src/components/CourseManager.tsx`:**
   - Кнопка создания: `t(locale, "courses.addNewCourse")`
   - Пустое состояние: `t(locale, "courses.noCoursesYet")`
   - Бейдж статуса: `t(locale, "courses.published")`
   - Сводка модулей и групп: `t(locale, "courses.modulesCount")`, `courses.groupsCount`
   - Учебная программа: `t(locale, "courses.curriculum")`, `courses.noModulesYet`
   - Модалка создания: `t(locale, "courses.createCourseModal")`, `courses.courseName`, `courses.courseDescription`
   - Плейсхолдеры и кнопки: `t(locale, "courses.titlePlaceholder")`, `descPlaceholder`, `cancel`, `creating`
4. **`src/app/center/students/[id]/page.tsx`:**
   - Подпись учителя: `t(locale, "students.teacherLabel", { name })`
   - Fallback урока: `t(locale, "students.lessonFallback")`
   - История перевода: `t(locale, "students.transferHistory", { from, to })`
   - Причина: `t(locale, "students.reasonLabel", { reason })`
5. **Компоненты главной SaaS-страницы (`src/components/landing/*`):**
   - 100% вынесены в `messages/uz.json` и `messages/ru.json` со строгой типизацией `LandingMessages`.
